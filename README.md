# TASK-MANAGER

## 📌 Description
This is a full-stack Task Manager web application built using Flask, PostgreSQL, and JavaScript.  
It allows users to register, login, and manage tasks (Create, Read, Update, Delete).

---

## 🚀 Features
- User Registration & Login (Session-based authentication)
- Add Tasks
- View Tasks
- Update Tasks
- Delete Tasks
- Task Analytics using Pandas & NumPy
- Real-time updates using SocketIO

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- Database: PostgreSQL
- Libraries: Pandas, NumPy, Flask-SocketIO, Werkzeug
